Privacy Policy — 3dosero (三次元オセロ)

Last updated: 2026-08-30

3dosero (published as "三次元オセロ" on the App Store) is a single-player / local-play 3D Othello game. This policy covers both the web version and the iOS app.

Data collection

This app does not collect, store, or transmit any personal information. Specifically, it does not:

  • require an account, sign-in, or any personal details
  • use analytics, tracking, or advertising SDKs
  • send gameplay data, device identifiers, or usage statistics to any server
  • share any data with third parties (there is no data to share)

Network access

The iOS app ships with its own copy of the game and CPU opponent files, so it does not need a network connection to play. The web version, by nature of being a website, is loaded over HTTPS from GitHub Pages like any other site, and loads a small number of third-party JavaScript libraries (three.js, onnxruntime-web) from public CDNs (jsDelivr) to render the 3D board and run the on-device CPU opponent. These libraries run entirely in your browser; no gameplay data is sent back to them or to us.

Children's privacy

Since no personal information is collected from anyone, this app does not knowingly collect personal information from children.

Changes to this policy

If this policy ever changes (for example, if online multiplayer is added in the future), this page will be updated and the "Last updated" date above will change accordingly.

Contact

Questions can be raised via the project's GitHub Issues.

プライバシーポリシー — 3dosero（三次元オセロ）

最終更新日: 2026-08-30

3dosero（App Store上の名称は「三次元オセロ」）は、1人プレイ・ローカル対戦の 立体オセロゲームです。このポリシーはWeb版・iOSアプリ版の両方に適用されます。

個人情報の収集について

本アプリは、個人情報を一切収集・保存・送信しません。具体的には:

  • アカウント登録・ログイン・個人情報の入力は不要です
  • アクセス解析・トラッキング・広告SDKは使用していません
  • 対局データ・端末識別子・利用状況をいかなるサーバーにも送信しません
  • 第三者へのデータ提供は行いません（提供するデータ自体が存在しません）

通信について

iOSアプリはゲーム本体・CPU対戦相手のファイルをアプリ内に同梱しているため、 プレイに通信は不要です。Web版はWebサイトである性質上、GitHub PagesからHTTPS で配信され、3D描画・端末内でのCPU対戦相手の推論のため、jsDelivr（CDN）経由で three.js・onnxruntime-webという2つのJavaScriptライブラリを読み込みます。 これらはブラウザ内でのみ動作し、対局データが外部に送信されることはありません。

お問い合わせ

GitHub Issues までご連絡ください。
