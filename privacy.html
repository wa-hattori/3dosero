Privacy Policy — 3dosero (三次元オセロ)

Last updated: 2026-08-31

3dosero (published as "三次元オセロ" on the App Store) is a 3D Othello game with CPU, local, and online opponents. This policy covers both the web version and the iOS app.

Account and personal information

This app does not require an account, sign-in, or any personal details (name, email, etc.) at any point, in any mode.

Online multiplayer

Online play (room codes and random matchmaking) is powered by Google Firebase (Cloud Firestore). To make this work, the app:

  • signs you into Firebase anonymously, which assigns a random session identifier (not tied to your name, email, or any other personal information, and not shared between devices or app reinstalls)
  • sends the board state and moves of the current online game to Firebase's servers so your opponent's device can see them in real time

No game data is retained beyond what's needed to run the match; this app does not build a profile of you or your play history. Firebase is operated by Google; see Firebase's privacy information. CPU and local (same-device) play never contact any server.

Advertising (iOS app only)

The iOS app shows an occasional interstitial ad (roughly once every few games) via Google AdMob. The web version never shows ads. On first use, iOS will ask for permission to allow tracking (App Tracking Transparency) — declining this is fully supported and just means you'll see non-personalized ads instead. AdMob may collect device and advertising identifiers as described in Google's advertising and measurement policy.

Analytics

This app does not use any separate analytics or crash-reporting SDK beyond what's described above (Firebase for online play, AdMob for ads on iOS).

Network access summary

CPU and local (same-device) play work fully offline — the iOS app ships its own copy of the game and CPU opponent files. Online play requires a network connection (Firebase). The iOS app may also contact Google's ad servers to load ads. The web version, by nature of being a website, is loaded over HTTPS from GitHub Pages, and also loads three.js and onnxruntime-web from a public CDN (jsDelivr) to render the 3D board and run the on-device CPU opponent; these run entirely in your browser.

Children's privacy

This app does not knowingly collect personal information from children. Ad content shown via AdMob is filtered according to this app's audience settings in AdMob.

Changes to this policy

If this policy changes again, this page will be updated and the "Last updated" date above will change accordingly.

Contact

Questions can be raised via the project's GitHub Issues.

プライバシーポリシー — 3dosero（三次元オセロ）

最終更新日: 2026-08-31

3dosero（App Store上の名称は「三次元オセロ」）は、CPU対戦・対人戦（同一端末）・ オンライン対戦に対応した立体オセロゲームです。このポリシーはWeb版・iOSアプリ版の 両方に適用されます。

アカウント・個人情報について

本アプリは、いずれのモードでも、アカウント登録・ログイン・氏名やメールアドレス 等の個人情報の入力を一切必要としません。

オンライン対戦について

オンライン対戦（ルームコード制・ランダムマッチング）はGoogle Firebase （Cloud Firestore）を利用しています。具体的には:

  • 匿名認証によりランダムなセッション識別子を割り当てます（氏名・メール アドレス等とは一切紐づかず、端末の変更やアプリの再インストールで 引き継がれることもありません）
  • 対局中の盤面・着手をFirebaseのサーバーに送信し、相手の端末にリアルタイムで 反映させます

対局の成立に必要な範囲を超えてデータを保持することはなく、プレイ履歴の プロファイリング等も行いません。FirebaseはGoogleが運営するサービスです（ Firebaseのプライバシー 情報）。CPU対戦・対人戦（同一端末）はサーバーと一切通信しません。

広告について（iOSアプリのみ）

iOSアプリでは、Google AdMobによるインタースティシャル広告を数局に1回程度 表示します。Web版に広告は一切表示されません。初回利用時、iOSのシステムが トラッキング許可（App Tracking Transparency）を確認しますが、許可しなくても 引き続きプレイでき、その場合は非パーソナライズ広告が表示されます。AdMobが 収集しうるデータについては Googleの 広告・測定に関するポリシーをご参照ください。

アクセス解析について

上記（オンライン対戦のFirebase、iOS広告のAdMob）以外に、別途のアクセス解析・ クラッシュレポートSDKは使用していません。

通信のまとめ

CPU対戦・対人戦（同一端末）は完全にオフラインで動作します（iOSアプリは ゲーム本体・CPU対戦相手のファイルをアプリ内に同梱）。オンライン対戦には 通信が必要です（Firebase）。iOSアプリは広告表示のためGoogleの広告サーバーとも 通信することがあります。Web版はWebサイトである性質上GitHub PagesからHTTPSで 配信され、3D描画・端末内でのCPU対戦相手の推論のためjsDelivr（CDN）経由で three.js・onnxruntime-webを読み込みます。これらはブラウザ内でのみ動作します。

お子様のプライバシーについて

本アプリは、いかなる利用者からも意図的に個人情報を収集することはありません。 AdMob経由で表示される広告コンテンツは、AdMob上で設定したアプリの対象年齢に 応じてフィルタリングされます。

お問い合わせ

GitHub Issues までご連絡ください。
