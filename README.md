# 3dosero — 3次元オセロ

8×8×8 の立体盤面で遊ぶオセロ（リバーシ）。通常のオセロと同じく、同一平面上だけでなく上下方向・斜め方向（3次元の全26方向）でも相手の石を挟んで自分の色に変えられる。

## コンセプト

- **盤面**: 8×8 の盤を8層積み重ねた 8×8×8 の立体グリッド。
- **ルール**: 石を置いたとき、26方向（同一平面8方向 + 上下1方向 + 立体斜め17方向）のいずれかで相手石の連続を自分の石で挟めれば反転する。
- **GUI**: 盤面は緑地に黒線のマス目、石を置ける場所は灰色でハイライト。マウス/タッチで視点を回転・拡大縮小でき、層ごとに表示を絞り込むオプションも備える。
- **配信形態**: まずは素の HTML/CSS/JS で実装し、HTTPS で静的サイトとして公開。将来的には App Store でのリリースも視野に入れる。
- **将来構想**: 敵対的生成ネットワーク（GAN）を用いた CPU 対戦相手の実装。
